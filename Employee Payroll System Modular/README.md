# Employee Payroll System (Java Capstone Project)

### Course Outcomes Addressed:
- **CO1 (Constructors):** Default, Parameterized, and Copy constructors implemented in `Employee.java`.
- **CO3 (File I/O & Exception Handling):** Dedicated file handling in `PayrollFileManager.java` using `FileWriter`, `BufferedWriter`, `FileReader`, and `BufferedReader`, with custom exception `InvalidSalaryException.java`.
- **CO4 (Collections):** Dynamic storage and search/delete queries using `ArrayList<Employee>`.
- **CO5 (Swing GUI):** Interactive dashboard interface in `PayrollSystemGUI.java`.

### Compilation and Execution:
1. Open terminal/command prompt in this folder.
2. Compile all source files:
   ```bash
   javac *.java
   ```
3. Run the GUI:
   ```bash
   java PayrollSystemGUI
   ```
